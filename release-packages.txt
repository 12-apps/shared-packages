# The publishable packages, in TOPOLOGICAL order (dependencies first).
#
# The single source of truth for what this repo releases. ci.yml loads it into
# PUBLISH_DIRS; release-watchdog.yml lets the scripts read it directly; and
# scripts/lib/release-state.mjs falls back to it whenever PUBLISH_DIRS is unset.
#
# Order is load-bearing for PUBLISHING and irrelevant to verifying: a package is
# released only after everything it depends on, so prepare-publish.mjs always
# resolves workspace:* interdeps to a version that already exists.
#
# Paths rather than names because payments ships as a nested workspace.
#
# `packages/discounts` sits LAST because it depends on shared-helpers (the
# search engine its admin list is built on), and shared-helpers is itself last
# among the packages that came before it.
